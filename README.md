# BLACKWATER — Silent Harbor

An open-source, single-player tactical FPS built with Three.js, React, and TypeScript. Infiltrate a rain-soaked freight terminal, neutralize nine hostiles, and reach extraction.

## Features

- Procedural terminal, containers, cranes, rain, wet pavement, and lighting
- Detailed first-person carbine with aiming, recoil, reloads, and muzzle effects
- Enemy navigation, cover-aware combat, and headshot detection
- Movement, sprinting, jumping onto low cover, and health recovery
- Ammunition resupply, mission completion, death, and restart
- Synthesized audio, adjustable sensitivity, and cinematic effects

All game art and audio are generated by the source. No proprietary Call of Duty assets are included. This is a focused browser prototype, not a commercial AAA game.

## Controls

| Action | Control |
| --- | --- |
| Move | WASD or arrow keys |
| Look | Mouse |
| Fire | Left mouse button |
| Aim | Hold right mouse button or toggle Q |
| Sprint | Left Shift |
| Jump | Space |
| Reload | R |
| Resupply | E near the marked supply crate at insertion |
| Pause | Escape |

Clear all nine enemies, then stand near the amber beacon at the far end of the terminal to extract. Use cover to recover health. A desktop browser with WebGL, a keyboard, and a mouse is recommended. Browsers that disallow pointer lock use free-cursor looking.

## Run locally

Use Node.js 24 (Node.js 22.13 or newer is supported).

```sh
npm ci
npm run dev
```

## Verify and build

```sh
npm test
npm run build
npm run preview
```

The build includes TypeScript checking. The tests verify reachable enemy positions and extraction, hits and headshots, obstruction by cover, recoil order, reload guards, swept collision, landing on low cover, death, and mission completion.

## Deploy to Vercel

Import this repository into Vercel. The included `vercel.json` selects Vite, runs `npm ci` and `npm run build`, and publishes `dist`. No environment variables or server-side services are required.

## Source guide

- `app/game/engine.ts` — controls, combat, physics, audio, enemy navigation, and mission state
- `app/game/environment.ts` — procedural environment and collision geometry
- `app/game/weapon.ts` — first-person weapon and hands
- `app/game/enemy.ts` — enemy operator assets and animation
- `app/page.tsx` and `app/globals.css` — game interface
